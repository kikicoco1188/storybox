# StoryBox

Landing page (`index.html`) + app (`app.html`). Plain files, no build step.

## Put it on GitHub Pages
1. Make a repository. Upload ALL files below to the TOP LEVEL of the repo (not inside a sub-folder):
   index.html, app.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, .nojekyll
2. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. Wait 1-2 minutes, then open  https://YOUR-NAME.github.io/YOUR-REPO/
